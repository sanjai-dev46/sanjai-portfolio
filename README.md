# Sanjai E — Full Stack Developer Portfolio

A modern, interactive portfolio website built with React JS featuring a live 3D starfield background, smooth scroll animations, and a complete showcase of my skills, projects, and work experience.

## Tech Stack
- React JS — UI and component architecture
- Three.js + React Three Fiber — 3D background animations
- Framer Motion — scroll-reveal and hover animations
- React Scroll — smooth section navigation
- React Icons — icon library

## Sections
- Hero — introduction with animated photo and stats
- About — background, education, and certifications
- Skills — frontend, backend, database, and tools
- Projects — 4 full-stack and frontend projects
- Experience — internship timeline
- Contact — email, phone, GitHub, LinkedIn
